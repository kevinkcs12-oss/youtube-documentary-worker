Why do cars, cafés, interfaces, logos and new buildings so often feel as if they share one visual language?

This documentary follows seven bounded evidence families—from object colour and vehicle markets to processing fluency, interface conventions, responsive identity, repeatable architecture and recommendation systems. The argument is not that everything is literally identical, or that one cause explains it all. It is that scale, familiarity, legibility, uncertainty and imitation can repeatedly reward the same low-friction choices.

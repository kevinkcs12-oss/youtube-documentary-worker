# Pilot 01 opening — real-asset assembly v0.1

Purpose: prove the real-asset path from licensed Pexels source pages to a deterministic Layer C render.

This is **not** the canonical 00:00–01:04 edit. It is a 30-second editorial/technical conform used to validate the first three real masters.

## Asset decisions

1. **Pexels 6775059 — Kindel Media — office exterior**
   - 3840×2160, ~11 s.
   - Strong fit for contemporary generic/corporate architecture.
   - Use as a convergence example, not as evidence that all offices look alike.

2. **Pexels 5243465 — Peggy Anke — café interior**
   - 1080×1920 portrait, ~16 s.
   - Rich wood, woven lighting, warm materials; visually more characterful than the script's deliberately generic café shorthand.
   - Keep as a partial-fit café example / visual counterpoint. Do not use it alone to imply standardized minimalism.

3. **Pexels 12187901 — Said — bookstore storefront**
   - 1280×720, 30 s.
   - Distinctive independent storefront with strong local character.
   - Best used as a deliberate counterexample to simplistic “everything is identical” framing.

## Editorial interpretation

The trio is useful precisely because it contains both convergence and resistance:
- office exterior = standardized corporate vocabulary;
- café = contemporary but materially expressive;
- bookstore = visibly particular/local.

That supports the documentary's evidence boundary: the world is not literally identical; repeated systems can narrow the visual field while exceptions remain.
